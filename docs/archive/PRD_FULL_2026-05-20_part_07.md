OpenHands, Claude Squad, Metaswarm을 보조 후보로 비교

```

```

## 29. 최종 방향성

Agent Control Room은 자체 IDE도, 단순 작업 보드도 아니다.

이 제품은 오픈소스 에이전트 작업 보드 위에 얹는 **개인 AI 개발 PM 레이어**다.

최종적으로 사용자는 이렇게 일하게 된다.

```txt
사용자:
“이 기능을 만들고 싶어.”

Agent Control Room:
“이 기능은 4개의 기술 작업으로 나뉩니다.
현재 Claude Code는 cooling_down 상태이므로,
1번 구현 작업은 Codex,
2번 UI 프로토타입은 Antigravity,
3번 구조 리뷰는 Claude Code 회복 후 진행하는 것이 좋습니다.

아래는 Codex에 바로 전달할 실행 프롬프트입니다.
또한 이 작업은 Vibe Kanban의 새 작업 카드로 연결할 수 있습니다.”
```

이것이 제품의 핵심 경험이다.

## 30. 이번 PRD의 핵심 변경점

기존 PRD와 비교해 이번 PRD는 다음을 명확히 한다.

```txt
1. Agent Control Room은 처음부터 전체 웹사이트를 자체 구축하지 않는다.
2. Vibe Kanban 같은 오픈소스 도구를 우선 검토한다.
3. 기존 구현물은 폐기하지 않고 Orchestrator Layer로 재해석한다.
4. 자체 작업 보드보다 기획 번역, AI 라우팅, 프롬프트, 핸드오프에 집중한다.
5. 오픈소스 베이스와 중복되는 기능은 매핑 후 정리한다.
6. 토큰 로테이션과 AI 도구 전환은 핵심 차별화 기능으로 유지한다.
```
